# Break the Tie

This challenge uses quantum amplitude estimation to estimate a discrete mean
and a second, direct encoding circuit to choose between the two mirror-phase
candidates.

Run from the repository root:

```powershell
.\.venv\Scripts\python.exe challenges\Group3\04_break_the_tie\submission.py
.\.venv\Scripts\python.exe -m pytest challenges\Group3\04_break_the_tie -q
```
