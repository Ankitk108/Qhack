# Pulse Optimization

This challenge builds a time-dependent one-qubit Hamiltonian, evolves it with a
single parametrized pulse operation, and optimizes the pulse coefficients for a
target state.

Run from the repository root:

```powershell
.\.venv\Scripts\python.exe challenges\Group3\09_pulse_optimization\submission.py
.\.venv\Scripts\python.exe -m pytest challenges\Group3\09_pulse_optimization -q
```
