# Implementing POVMs

This challenge constructs a two-qubit unitary dilation for a three-outcome
single-qubit POVM and verifies the resulting computational-basis probabilities.

Run from the repository root:

```powershell
.\.venv\Scripts\python.exe challenges\Group3\07_implementing_povms\submission.py
.\.venv\Scripts\python.exe -m pytest challenges\Group3\07_implementing_povms -q
```
