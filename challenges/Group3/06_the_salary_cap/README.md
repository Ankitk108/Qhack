# The Salary Cap

This challenge uses PennyLane's symbolic resource estimator to find the largest
quantum phase-estimation register that fits a fixed logical T-gate time budget.

Run from the repository root:

```powershell
.\.venv\Scripts\python.exe challenges\Group3\06_the_salary_cap\submission.py
.\.venv\Scripts\python.exe -m pytest challenges\Group3\06_the_salary_cap -q
```
