# Personal Best (Silver)

This is the Silver version of the arbitrary-unitary synthesis challenge. The
supplied complete program, including its grader and public cases, is preserved
in `submission.py`.

Run from the repository root:

```powershell
.\.venv\Scripts\python.exe challenges\Group3\05_personal_best_silver\submission.py
.\.venv\Scripts\python.exe -m pytest challenges\Group3\05_personal_best_silver -q
```
