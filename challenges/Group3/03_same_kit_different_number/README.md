# Same Kit, Different Number

This challenge determines whether two single-qubit unitaries differ only by a
global phase, extracts that phase, and exposes it through a controlled
phase-kickback circuit.

Run from the repository root:

```powershell
.\.venv\Scripts\python.exe challenges\Group3\03_same_kit_different_number\submission.py
.\.venv\Scripts\python.exe -m pytest challenges\Group3\03_same_kit_different_number -q
```
